# BuddyStudy 1.3.0 store creative

The user requested advertising-style screenshots benchmarked against the Korean
iPhone Education free Top 10. This is a visual benchmark, not a claim that
BuddyStudy has a Top 10 ranking. Final compositions use native screenshots
of the integrated release candidate and localized headline layers.

## Supporting illustration

`learning-tree-accent.png` was generated with the built-in image generation
tool, using the existing BuddyStudy brand-logo image as a style reference.
It is decorative, not an app interface or a claim about a feature.

Prompt:
> Use case: ads-marketing. Asset type: decorative brand illustration for a premium iOS education app App Store screenshot series. The supplied image is a BRAND STYLE REFERENCE ONLY. Create a new minimal sculptural learning-tree motif based on its three circular nodes and softly branching dark stem. Use the reference brand's deep ink black, forest green, clear blue, and warm golden yellow. Three glossy matte ceramic ring nodes connected with a smooth dark branching stem, refined soft 3D depth, tactile studio lighting, friendly but mature educational brand. Isolated cutout on a genuinely transparent background. Square composition, entire object visible with generous clear margin. No text, no letters, no logo wordmark, no phone, no UI, no person, no owl or competitor mascot, no trophies, no rankings, no distracting confetti. The illustration is a subtle supporting accent behind actual app screenshots, not a fabricated interface. Preserve the recognizable three-ring branching-tree concept while making it beautifully dimensional.

## Six-panel composition concept

`composition-concept.png` was generated as a layout reference using the brand
accent and an earlier native learning screenshot. It is not an upload asset and
its generated interface is never used in the final artwork. The final renderer
uses the exact current native captures.

Brief: a 3×2 concept board of six tall App Store panels, one large two-line Korean
benefit headline per panel, one short support sentence, alternating off-white and
cobalt blue, deep ink text, and one large native phone proof. Small tree accents
on panels 1 and 5 only. No competitor motifs, rankings, badges, testimonials,
learning-speed claims, or invented features. The exact approved copy is stored
in `copy.json`. The final order is learning feedback, follow-up, public feed,
study tree, topic progress, and custom question.

The implementation deliberately keeps a straight, completely visible device
rather than the concept's tilted/cropped first device. It preserves the native
capture's light appearance. A small BuddyStudy wordmark and three-color cue above
the headline were added after the first native composition review.
