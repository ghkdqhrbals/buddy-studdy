공유할 정보

  • 스터디내가 저장한 스터디, 학습 주제와 트리
  • 학습 기록질문과 힌트, 내 답변, 점수, 피드백과 해설
  • 통계주제별 점수, 학습 통계와 학습 추이

허용되는 작업

ChatGPT가 내 학습 기록을 읽고, 대화에서 복습이나 학습 분석에 활용할 수 있습니다. 비공개로 저장한 학습 내용도 조회 결과에 포함될 수 있습니다. 질문을 새로 만들거나 답변을 제출하는 권한은 없으며, 기록을 수정하거나 삭제할 수도 없습니다.

공유하지 않는 정보

API 키와 비밀번호, 이력서, 개인 관심사 프로필, 다른 사용자의 기록은 이 연결로 조회할 수 없습니다.

ChatGPT로 전달되는 내용

ChatGPT에서 조회한 학습 내용은 OpenAI로 전송됩니다. 전달된 내용은 OpenAI의 개인정보 처리방침과 내 ChatGPT 계정 또는 워크스페이스의 데이터 설정에 따라 처리되며, 해외에서 처리될 수 있습니다.

연결 기간과 해제

연결은 동의한 날부터 최대 30일 동안 유지됩니다. 그동안 매번 로그인하지 않아도 기록을 조회할 수 있고, 기간이 지나면 다시 동의해야 합니다.

연결 관리 화면에서 언제든 해제할 수 있습니다. 해제하면 이후 조회는 즉시 차단되지만, 이미 ChatGPT 대화에 전달된 내용은 삭제되지 않습니다. 해당 내용은 ChatGPT에서 별도로 관리해야 합니다.

연결 관리 열기

연결은 선택 사항입니다. 허용하지 않아도 BuddyStudy 앱은 계속 사용할 수 있습니다.

연결을 해제하면 더 이상 내 기록을 조회할 수 없습니다. 이미 전달된 내용은 ChatGPT에서 별도로 관리하세요.
