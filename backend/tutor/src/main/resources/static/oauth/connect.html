BUDDYSTUDY × CHATGPT

내 학습을 대화로 이어가세요

BuddyStudy 계정을 연결하면 ChatGPT에서 내 학습 기록을 살펴보고 복습할 수 있어요.

앱의 프로필에 표시된 이메일을 입력하세요. Apple 이메일 가리기를 사용했다면 릴레이 주소를 입력하세요.

ChatGPT에 허용할 정보

  • 내 스터디와 학습 주제
  • 질문, 내 답변, 점수와 피드백
  • 주제별 통계와 학습 추이

조회한 학습 내용은 연결한 ChatGPT로 전달됩니다. 이 연결로 학습 내용을 생성·수정·삭제하거나 API 키, 이력서, 다른 사람의 기록을 조회할 수는 없습니다. 연결은 최대 30일간 유지되며 다시 연결할 때 재동의합니다.

연결된 계정 관리

연결을 해제하면 해당 연결의 조회 권한이 즉시 만료됩니다. 이미 ChatGPT 대화에 전달된 내용은 ChatGPT에서 별도로 관리해 주세요.
