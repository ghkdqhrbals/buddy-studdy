BuddyStudy · ChatGPT 학습 기록 연결 안내

2026년 10월 20일 · 선택 기능

연결 목적과 제공 정보

사용자가 ChatGPT에서 복습과 학습 분석을 요청할 수 있도록, 별도 동의 후 본인의 스터디·주제, 질문·힌트, 답변, 점수, 피드백·해설과 주제별 통계·학습 추이를 연결한 ChatGPT에 제공합니다. 조회 결과에는 비공개 학습 내용이 포함될 수 있습니다. API 키, 비밀번호, 이력서, 개인 관심사 프로필과 다른 사용자의 기록은 이 읽기 전용 연결의 제공 대상이 아닙니다.

받는 서비스와 이용자의 선택

연결한 서비스는 OpenAI의 ChatGPT입니다. 연결된 대화에서 조회한 결과는 OpenAI로 전송되며 OpenAI의 개인정보 처리방침과 해당 계정·워크스페이스의 데이터 설정에 따라 처리됩니다. 해외에서 처리될 수 있습니다. 연결은 선택 사항이며 연결하지 않아도 BuddyStudy 앱을 계속 사용할 수 있습니다.

본인 확인과 허용 범위

앱 프로필의 계정 이메일로 발송한 인증번호로 본인을 확인합니다. 인증 요청은 10분 안에 완료해야 하며 인증번호는 최대 5번 입력할 수 있습니다. 같은 이메일의 계정이 여러 개면 연결하지 않습니다. learning:read는 본인 기록 조회 권한입니다. offline_access를 허용하면 매번 로그인하지 않고 연결을 갱신할 수 있습니다. 생성·수정·삭제 권한은 제공하지 않습니다.

보유 기간과 연결 해제

접근 토큰은 최대 15분, 갱신 권한은 최초 동의부터 최대 30일입니다. 서버는 토큰·인증번호·브라우저 비밀값의 해시, 계정·클라이언트·권한 범위, 동의 버전·시각과 만료 정보를 보관합니다. 만료된 연결과 갱신 이력은 정기 삭제하며 회원탈퇴 시 함께 삭제합니다. 보안상 요청 횟수 제한용 해시 키는 Redis에 최대 1시간 보관합니다. 백업은 기존 개인정보 처리방침을 따릅니다.

철회와 이미 전달된 내용

BuddyStudy 연결 관리 화면에서 본인 확인 후 연결을 해제하면 서버의 조회 권한이 즉시 만료됩니다. 연결 해제는 이미 ChatGPT 대화에 전달된 내용을 삭제하지 않습니다. 해당 내용은 ChatGPT의 대화·데이터 관리 기능을 사용해 별도로 관리해 주세요.
