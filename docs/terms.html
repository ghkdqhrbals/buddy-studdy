1. 서비스 개요

BuddyStudy는 사용자가 입력한 주제와 난이도에 맞춰 짧은 학습 질문을 생성하고, 답변 기록과 통계를 관리하는 iOS 앱입니다. 일부 기능은 사용자의 OpenAI API 키, Apple Push Notification service, BuddyStudy 백엔드, Google Login 또는 이메일 로그인을 사용할 수 있습니다.

이 약관은 BuddyStudy 앱, 백엔드 동기화, 공개 질문, 로그인 기반 기능을 사용할 때 적용됩니다.

2. 계정과 로그인

  • 기본 학습 기능은 앱 계정 없이 사용할 수 있으나, 기록 동기화, 통계, 공개 질문, 댓글 등 일부 기능은 로그인이 필요할 수 있습니다.
  • 사용자는 본인이 관리하는 Google 계정 또는 이메일로 로그인해야 하며, 계정 접근 권한을 안전하게 관리해야 합니다.
  • 잘못된 기기 정보, 만료된 토큰, 삭제된 계정으로 접근하는 경우 앱은 재로그인을 요구할 수 있습니다.

3. 학습 데이터와 공개 질문

  • 사용자가 작성한 답변, 학습 기록, 설정, 통계는 학습 경험 제공과 동기화를 위해 저장될 수 있습니다.
  • 공개로 설정한 질문 또는 댓글은 다른 사용자가 볼 수 있습니다. 개인정보, 민감정보, 타인의 권리를 침해하는 내용은 공개하지 않아야 합니다.
  • 부적절한 공개 콘텐츠는 신고, 숨김, 삭제 또는 계정 제한 대상이 될 수 있습니다.

4. AI 결과와 사용자 책임

AI가 생성한 질문, 피드백, 해설, 점수는 학습 보조 정보이며 정확성이나 완전성이 보장되지 않습니다. 중요한 의사결정, 시험, 업무, 법률, 의료, 금융 판단에는 사용자가 별도로 검증해야 합니다.

사용자의 OpenAI API 키를 사용하는 기능의 비용과 사용량은 사용자의 OpenAI 계정 정책에 따릅니다.

5. 사용 제한

  • 서비스를 공격, 과부하, 우회, 스팸, 자동화 남용, 권한 없는 접근 목적으로 사용할 수 없습니다.
  • 불법적이거나 타인의 권리를 침해하는 콘텐츠를 생성, 저장, 공유할 수 없습니다.
  • 서비스 안정성 또는 다른 사용자의 이용을 방해하는 경우 기능 제한 또는 계정 제한이 적용될 수 있습니다.

6. 서비스 변경 및 중단

BuddyStudy는 기능 개선, 보안, 운영상 필요에 따라 앱 또는 백엔드 기능을 변경하거나 일시 중단할 수 있습니다. 외부 서비스 장애, 네트워크 문제, 사용자의 API 키 또는 계정 설정 문제로 일부 기능이 동작하지 않을 수 있습니다.

7. 면책 및 책임 제한

BuddyStudy는 가능한 안정적으로 서비스를 제공하기 위해 노력하지만, 모든 데이터 보존, AI 결과의 정확성, 외부 서비스의 지속 제공을 보장하지 않습니다. 법에서 허용하는 범위 내에서 BuddyStudy의 책임은 직접적이고 합리적으로 예측 가능한 손해로 제한됩니다.
