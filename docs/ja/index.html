理解が深まるほど、AIの答えも鮮明になります。

短い問題に自分の言葉で答え、フィードバックと解説を確認しながら、トピックごとの成長を積み重ねましょう。

AIによる問題生成と採点はBuddyStudyのバックエンドを通じて提供されます。

集中できる学習サイクル

  • トピックと難易度に合った短い問題を作成します。
  • 入力中の回答を保存し、提出後にフィードバックと詳しい解説を確認します。
  • 学習ツリー、検索できる履歴、トピック別統計から次の学習を決めます。

継続のための機能

好きな頻度で問題の通知を受け取り、メインテーマと下位トピックを整理しながら学習履歴を積み上げられます。

BuddyStudy for ChatGPT

BuddyStudyアカウントを連携すると、ChatGPTでも学習テーマを作成し、問題への回答を提出して採点を受け、学習履歴やトピック別統計を確認できます。プロフィール、保存した履歴書、関心分野の参照には別途同意が必要です。既存アカウントの出題上限が適用されます。

アプリと同じApple、Googleまたはメールのアカウントでログインし、アクセス権限を確認してください。連携のご案内 · 連携サポート
