총칙

BuddyStudy는 학습 질문 생성과 답변 채점을 제공하는 무료 학습 앱입니다. 기본 학습 기능은 별도 앱 계정 없이 사용할 수 있으며, 학습 기록과 설정은 기기 중심으로 저장됩니다. 다만 AI 기능, 서버 예약 push 알림, 백엔드 동기화, 로그인 기반 커뮤니티 기능을 제공하기 위해 BuddyStudy 백엔드와 외부 서비스가 일부 정보를 처리할 수 있습니다. BuddyStudy는 개인정보를 판매하지 않습니다.

공개 질문 목록은 로그인하지 않아도 읽을 수 있습니다. 댓글 작성, 좋아요, 신고, 프로필 관리, 학습 기록, 통계, 학습 상세 등 사용자별 기능은 이메일 로그인 또는 Google Login 이후 사용할 수 있습니다.

사용자가 질문 공개를 켠 상태에서 질문을 생성한 경우, 다른 사용자에게 질문 본문, 주제, 난이도, 생성 시각, 좋아요 수, 댓글 수 등 제한된 정보와 공개 프로필이 표시될 수 있습니다. 공개 질문 상세에서는 사용자가 공개한 질문에 달린 공개 댓글과 작성자 공개 프로필도 표시될 수 있습니다. 답변 초안, 비공개 답변, 점수, 피드백, 해설, APNs 토큰, 기기 인증 정보는 공개 질문 목록에 표시하지 않습니다.

이 개인정보 처리방침은 개인정보보호위원회의 「개인정보 처리방침 작성지침」(2026.4. 개정)에서 안내하는 명확성, 투명성, 접근성 원칙을 참고하여 작성되었습니다.

1. 개인정보의 처리 목적

BuddyStudy는 다음 목적을 위해 필요한 범위에서 정보를 처리합니다.

  • 학습 주제, 난이도, 질문 간격 등 앱 설정 저장
  • BuddyStudy 백엔드를 통한 AI 학습 질문 생성 및 답변 채점
  • 답변 초안, 학습 기록, 점수, 피드백, 해설, 주제별 통계 제공
  • 백엔드 동기화를 통한 학습 설정, 기록, 통계 유지
  • 알림 허용 시 로컬 알림 또는 서버 예약 push 알림 제공
  • 이메일 로그인 또는 Google Login 사용 시 커뮤니티 프로필, 다른 사용자 질문, 댓글, 좋아요, 신고 처리 제공
  • 계정 보안, 장애 대응, 부정 이용 방지를 위한 내부 운영 로그 처리

3. AI 처리 방식

AI 질문 생성과 답변 채점은 BuddyStudy 백엔드가 외부 AI 제공업체에 필요한 요청을 중계하는 방식으로 제공됩니다.

  • 사용자는 AI 제공업체 자격 증명을 앱에 입력하거나 백엔드에 저장할 필요가 없습니다.
  • AI 요청에는 학습 주제, 난이도, 질문, 답변, 관련 프롬프트 등 기능 제공에 필요한 텍스트가 포함될 수 있습니다.
  • BuddyStudy 백엔드는 외부 AI 제공업체 응답을 받아 질문, 피드백, 해설, 점수 형태로 앱에 반환합니다.
  • AI 요청과 응답은 운영 로그에 제한적으로 기록될 수 있으며, 인증 정보는 로그에서 마스킹됩니다.

AI 결과는 학습 보조용이며 정확성이나 완전성이 보장되지 않습니다.

4. 커뮤니티 프로필 및 신고 처리

공개 질문 목록 조회는 로그인 없이도 사용할 수 있습니다. 댓글 작성, 좋아요, 신고, 프로필 관리 등 사용자별 커뮤니티 기능은 이메일 로그인 또는 Google Login 이후 사용할 수 있습니다.

사용자가 질문 공개를 켜고 질문을 생성한 경우, 다른 사용자에게 질문과 함께 공개 프로필(표시 이름, 프로필 이미지 또는 캐릭터, 소개말)이 표시될 수 있습니다. 공개 질문 상세에는 공개 댓글, 댓글 작성자의 공개 프로필, 좋아요 수, 댓글 수도 표시될 수 있습니다.

이메일 주소와 Google 계정 식별자는 계정 연결과 보안 확인에 사용되며 공개 질문 목록에는 표시하지 않습니다. 질문 신고 시 신고 내용은 백엔드에 저장되고, 운영자 확인을 위해 지정된 Gmail 주소로 전달될 수 있습니다.

5. 개인정보의 처리 및 보유 기간

앱 설정, 학습 기록 및 통계는 사용자가 앱을 사용하는 동안 기기 내에 보관됩니다. 학습 기록은 앱 설정의 최대 기록 개수에 따라 보관되며, 사용자는 앱 안에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다.

BuddyStudy 백엔드에 저장된 기기 정보, 설정, 질문 및 채점 기록, 계정 정보, 커뮤니티 프로필, 댓글, 좋아요, 신고 정보는 기능 제공과 동기화를 위해 보관됩니다. 사용자가 앱에서 기록을 삭제하면 백엔드의 해당 기록과 관련 공개 질문/신고 연결 정보도 즉시 삭제됩니다.

계정을 삭제하면 해당 계정의 커뮤니티 프로필, 로그인 연결 정보, 공개 질문, 관련 학습 기록이 즉시 삭제됩니다. 앱을 삭제하면 iOS 동작에 따라 기기 내 로컬 데이터가 삭제됩니다. 백엔드에 남아 있을 수 있는 기기 단위 데이터 삭제가 필요한 경우 아래 문의처로 요청할 수 있습니다.

6. 개인정보의 파기 절차 및 방법

사용자가 앱에서 기록을 삭제하면 해당 기록은 앱의 로컬 저장소와 백엔드 저장소에서 즉시 삭제됩니다. 공개 질문 목록에 표시되던 항목과 관련 연결 정보도 함께 삭제됩니다.

계정 삭제 시 커뮤니티 프로필, 로그인 연결 정보, 공개 질문, 관련 학습 기록은 복구할 수 없도록 삭제됩니다. 앱 삭제 시 로컬 앱 데이터는 iOS의 앱 데이터 삭제 방식에 따라 제거됩니다.
