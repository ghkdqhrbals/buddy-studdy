BuddyStudy ChatGPT 학습 연결 안내

2026년 10월 21일

연결 목적과 정보

ChatGPT에서 스터디와 주제를 만들고, 질문을 요청하고, 답변을 제출해 채점받으며 학습 기록을 관리하는 선택 기능입니다. 본인 계정의 스터디와 주제, 질문과 힌트, 답변, 점수, 피드백과 해설, 주제별 통계와 음성 학습 기록을 조회할 수 있습니다. 조회 결과에는 비공개 학습 내용이 포함될 수 있습니다. API 키, 비밀번호, 이력서, 개인 관심사 프로필과 다른 사람의 기록은 제공하지 않습니다.

허용하는 작업

learning:read는 학습 조회, learning:write는 스터디와 주제 생성 및 변경, 질문 생성과 건너뛰기, 답변 제출과 채점, 후속 질문과 직접 작성한 질문 저장 권한입니다. learning:delete는 사용자가 대상을 확인한 스터디와 학습 기록의 삭제 권한입니다. 삭제한 데이터는 복구할 수 없습니다. 동의 화면에 표시한 범위만 허용하며 기존 읽기 전용 연결은 다시 동의해야 변경 권한을 받습니다.

이용 한도

질문 생성과 채점에는 기존 BuddyStudy 계정의 요금제와 이용 한도가 적용됩니다. 스터디와 주제 생성은 질문 한도를 사용하지 않습니다. 이 연결에서 결제나 구독 변경은 처리하지 않습니다.

OpenAI로 전달되는 내용

연결된 ChatGPT 대화에서 사용한 조회 결과와 작업 결과는 OpenAI로 전송됩니다. OpenAI의 개인정보 처리방침과 해당 계정의 데이터 설정에 따라 처리되며 해외에서 처리될 수 있습니다. 연결하지 않아도 BuddyStudy 앱을 계속 사용할 수 있습니다.

인증과 보관

계정 이메일로 발송한 인증번호 또는 이메일 가입 계정의 기존 비밀번호로 본인을 확인합니다. 인증 요청은 10분 안에 완료해야 하며 인증번호는 최대 5번 입력할 수 있습니다. 접근 토큰은 최대 15분, 갱신 권한은 최초 동의부터 최대 30일입니다. 서버는 토큰과 인증번호의 해시, 계정과 클라이언트, 권한 범위, 동의 버전과 시각, 만료 정보를 보관합니다. 만료된 연결은 정기 삭제하며 탈퇴 시 함께 삭제합니다. 요청 제한용 해시는 최대 1시간 보관하며 백업은 개인정보 처리방침을 따릅니다.

연결 해제

연결 관리에서 본인 확인 후 해제하면 이후 조회와 변경 권한이 즉시 만료됩니다. 이미 ChatGPT에 전달한 내용은 별도로 ChatGPT의 대화 및 데이터 관리 기능에서 관리해 주세요.
