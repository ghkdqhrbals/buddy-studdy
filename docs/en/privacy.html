Privacy Policy

Last updated: June 10, 2026

Overview

BuddyStudy is a free study app that uses your own OpenAI API key to generate study questions and grade answers. Core study features and public question browsing can be used without a separate app account. The app is designed to keep study records and settings local-first, and uses the backend where needed for AI routing, scheduling, synchronization, push delivery, and account-based community features.

If you enable question visibility and create a question, other users may see limited public information such as question text, topic, difficulty, creation time, like count, comment count, and your public profile. Public question details may also show public comments and commenter public profiles. Answer drafts, private answers, scores, feedback, explanations, OpenAI API keys, APNs tokens, and device credentials are not shown in public question lists.

BuddyStudy does not sell personal data and does not intentionally collect government identifiers or sensitive personal information.

Information Stored By The App

BuddyStudy may store the following information on your device:

  • Study topic, level, prompt, interval, language, notification, record retention, question visibility, and app settings.
  • Your OpenAI API key, if you enter one.
  • Study questions, answer drafts, graded answers, scores, feedback, explanations, and topic statistics.
  • Backend device ID, hashed client secret, APNs device token, platform, APNs environment, app language, and timezone when backend features are used.
  • If you sign in for community features: email address, password hash, email verification code and expiry, Google account subject, Google ID token verification result, sign-in method, display name, avatar URL or avatar character/color, public bio, and public page access settings.
  • Community activity such as question visibility, likes, public comment body, comment author, comment creation/deletion time, and public question engagement counts.
  • If you report a community question: reported question ID, reason, optional message, reporter device ID, and submission time.
  • Internal operation and security logs such as request ID, request time, HTTP method, path, query, status code, duration, error code/reason, and limited request/response bodies. API keys, passwords, verification codes, ID tokens, access tokens, and client secrets are redacted from these logs.

Community Profiles And Reports

Public question browsing is available without signing in. Writing comments, liking questions, reporting questions, and managing a profile require email login or Google Login.

Your public profile may show your display name, avatar or character, and bio to other users when they view a question you chose to make public. Public question details may show public comments, commenter public profiles, like counts, and comment counts. Your email address and Google account identifier are used for account linking and are not shown in public question lists.

When you report a community question, BuddyStudy stores the report and may forward it to the operator email address for moderation. Reports are used only for abuse review and service operation.

OpenAI API

When you generate a question or grade an answer, BuddyStudy sends the required study text to OpenAI using the API key you provide. OpenAI processes that information under OpenAI's own terms and privacy practices. Your OpenAI API usage and billing are managed through your own OpenAI account.

BuddyStudy does not provide an OpenAI account or API key for normal use.

Backend Storage of OpenAI API Key

Your OpenAI API key is a credential, so BuddyStudy treats it as sensitive. The backend may store it when needed for AI requests, scheduled push delivery, or backend synchronization.

  • On the backend, the key is stored as an encrypted value, never as plain text.
  • Encryption uses AES-256-GCM with an internal server master key (BACKEND_MASTER_KEY).
  • Backend storage is limited to the app features that need server-side AI routing, synchronization, or scheduled push delivery.
  • BuddyStudy does not expose the decrypted key in API responses or application logs.
  • When you clear the key in settings or disable scheduling, backend usage stops immediately and no new key sync is made.

If you prefer not to use server-side AI features, do not enter an OpenAI API key or disable the relevant backend features in the app.

Notifications

If you allow notifications, BuddyStudy may schedule local notifications or receive server-scheduled push notifications to remind you about study questions. You can manage notification permission in iOS Settings.

For server-scheduled push delivery, BuddyStudy may store an APNs device token, study schedule, notification preferences, and an encrypted OpenAI API key on the BuddyStudy backend. This backend is used to generate and deliver scheduled study-question notifications and keep backend records in sync.

Data Sharing

BuddyStudy does not sell your personal data. The app may send data to OpenAI when you use AI question generation or grading, may use Google Login or email login for community identity, may use Gmail SMTP for email verification codes and report forwarding, may use the BuddyStudy backend for AI routing, settings/records sync, scheduled notification delivery, community profiles, public questions, comments, likes, reports, and operation logs, and may use Amazon Web Services for backend infrastructure.

OpenAI, Apple Push Notification service, Google Login, Gmail SMTP, and Amazon Web Services may process data in countries where they operate, including the United States. Transfers occur over encrypted connections when you use the relevant feature, and each provider's own terms and privacy practices apply.

Retention And Deletion

You can delete study records in the app. Deleted backend records are immediately removed together with related public-question and report references. Deleting the app removes local app data from the device according to iOS behavior.

When you remove or change the OpenAI API key from app settings, the key is replaced, no longer used, or removed where it is no longer needed for service operation. Deleting your account immediately removes the community profile, sign-in mapping, public questions, and related study records for that account.

Internal operation and security logs are retained only as needed for service operation, security, abuse prevention, and troubleshooting.

Your Choices And Rights

You can view and delete study records in the app, disable question visibility, make a public question private, delete your account, change notification permission in iOS Settings, and change or remove your OpenAI API key in the app. For access, correction, deletion, suspension, public-question/comment removal, community profile deletion, or operation-log requests related to backend data, contact the developer by email.

Children

BuddyStudy is not directed to children under 14. If you believe a child has provided personal information through the app, please contact us.

Automated Decisions

Grading and feedback are AI-generated study aids. They are not used for decisions that have legal or similarly significant effects. If you need an explanation of a grading result or AI feedback, contact the developer by email.
